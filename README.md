# Tiny Tales

## Channel

YouTube @TinyToonTownTVz

## Purpose

Track Tiny Tales toddler (ages 2–4) educational animated videos.

## Rules

- Original characters only (no copyrighted characters or music).
- Educational focus: ABCs, numbers, colors, shapes, animals, and nursery rhymes.
- Made for Kids when applicable.
- Never ask kids for personal info.
- Never publish without Levi's explicit approval.

## How tracking works

Append one line per video to TRACKING.md. Optionally close or update related GitHub issues.
